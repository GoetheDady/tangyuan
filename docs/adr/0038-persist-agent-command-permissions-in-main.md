# 在 Main 持久化 Agent 命令许可

用户可以把一条非高风险命令授予长期的 Agent 命令许可。许可严格按 Agent、`cwd` 与完整命令匹配，对该 Agent 的所有会话生效，但不跨 Agent 或工作目录。高风险命令始终需要逐次确认，不能写入长期许可。

Main 进程中的 Agent 命令许可 module 是待审批状态、许可匹配和持久化的唯一事实来源。Renderer 只投影命令审批这一对话动作，并提交“允许本次”“长期允许”或“拒绝”的用户决定；Renderer 不保存许可，也不根据历史决定自动批准。

许可文件使用显式版本和原子替换写入。命令执行前由 Runtime 先应用当前高风险策略：命中高风险时忽略长期许可，只创建本次审批。

本决策取代 ADR-0027 中“MVP 不提供永久允许”以及审批卡“只提供允许本次和拒绝”的部分。ADR-0027 关于 Main 持有审批状态、展示完整命令与 `cwd`、明确 macOS 用户权限、取消或退出时自动拒绝的其余决策继续有效。
