# 彻底切换产品身份为元宵

项目将产品中文名从“汤圆”改为“元宵”，英文标识从 `tangyuan` 改为 `yuanxiao`，并在仓库名、本地仓库目录、程序标识、代码符号、包作用域、默认 Agent、运行数据目录和文档中彻底切换。项目尚未正式发布，因此不为旧名称、旧标识或 `~/.tangyuan` 数据提供兼容层或自动迁移，以免长期保留双重身份和迁移负担；需要保留的开发数据在切换前另行处理。

现有黑芝麻与糯米白视觉系统保持不变，只替换产品名称、设计稿标识和仍为 Electron 模板资源的应用图标，不借改名重做界面。

新应用图标使用抽象的糯米白外形、黑芝麻核心与少量朱砂红识别点，不使用文字、碗勺或写实餐饮插画，延续安静桌面工具的产品定位。

用户可见名称统一使用“元宵”，代码、文件、目录、环境变量、IPC 和包名等技术标识统一使用小写 `yuanxiao`；macOS 应用标识使用 `com.goethedady.yuanxiao`，workspace 包作用域使用 `@yuanxiao/*`。

当前代码、配置、测试、文件名、活跃文档和设计稿不再使用旧身份；ADR、历史 issue、research 文档及 Git 历史可以在准确描述旧状态时保留旧名，不为追求零文本命中而改写历史来源。

实施切换时直接删除现有 `~/.tangyuan` 运行数据，不备份、不迁移；元宵只从全新的 `~/.yuanxiao` 初始化。该删除是已接受的不可恢复结果。

根包、桌面包、安装产物和界面统一使用 `0.1.0` 版本；界面从构建元数据读取版本，不再维护硬编码版本文案。
