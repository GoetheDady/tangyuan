# 在正常回复回合内更新 Agent 灵魂与用户画像

Agent 根据正常对话的完整上下文自行判断是否需要长期更新 Agent 灵魂或用户画像，并在给出最终回复前调用 Main 提供的受控 `update_soul` 或 `update_user_profile` 工具。汤圆不再在主回复之后运行隐藏的第二次模型维护回合，因为它会继续占用聊天会话、拆散一次决策的上下文，并重复一轮模型调用；受控工具统一承担权限检查、自动备份、敏感信息拒绝和版本冲突检查，普通文件工具不能直接修改这些文件。更新被拒绝或执行失败时不终止正常回复，但 Agent 必须在最终回复中明确告知用户失败及原因。

首次初始化同样使用这两个受控工具。每次写入成功后，Runtime 检查 `soul.md` 与共享 `user.md` 是否都存在且非空；两者就绪时由 Runtime 删除 `bootstrap.md`，不要求 Agent 直接操作初始化状态文件。
