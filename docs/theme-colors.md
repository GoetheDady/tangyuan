# 汤圆主题色

## 决策

汤圆第一版先固定这套颜色，不继续推进 UI 设计稿。

主题方向：

- 糯米白做大面积背景。
- 米浆白做浮层和输入区。
- 芝麻黑做品牌主色和关键操作。
- 红豆色只用于危险、错误或轻提示。
- 豆青色只用于成功、连接、运行中状态。

**主题色** 指产品长期使用的一组基础颜色。

**语义色** 指按用途命名的颜色，例如 `background` 表示背景色，`danger` 表示危险状态色，而不是只按视觉名称命名。

## 色板

| 语义名         | 中文名   | 色值      | 用途                   |
| -------------- | -------- | --------- | ---------------------- |
| `background`   | 糯米白   | `#FBF7EF` | 页面主背景             |
| `surface`      | 米浆白   | `#FFFDF8` | 卡片、面板、输入区     |
| `surface-soft` | 浅米灰   | `#F1E9DE` | 选中态、次级浮层       |
| `text`         | 芝麻深黑 | `#211B16` | 主文字                 |
| `text-muted`   | 温灰褐   | `#7D7166` | 次级文字、说明文字     |
| `border`       | 米灰线   | `#DED2C2` | 边框、分割线           |
| `brand`        | 黑芝麻   | `#1F1A15` | 品牌主色、主按钮       |
| `brand-soft`   | 芝麻糊   | `#3A322A` | 品牌悬停态、强调文字   |
| `success`      | 豆青色   | `#5F8B70` | 运行中、连接成功、完成 |
| `danger`       | 红豆色   | `#B66C63` | 错误、取消、危险操作   |
| `focus`        | 糯米深边 | `#8B7563` | 输入框焦点、键盘焦点   |

## CSS 变量

```css
:root {
  --color-background: #fbf7ef;
  --color-surface: #fffdf8;
  --color-surface-soft: #f1e9de;
  --color-text: #211b16;
  --color-text-muted: #7d7166;
  --color-border: #ded2c2;
  --color-brand: #1f1a15;
  --color-brand-soft: #3a322a;
  --color-success: #5f8b70;
  --color-danger: #b66c63;
  --color-focus: #8b7563;
}
```

## 使用约束

- 不使用桂花金。
- 不使用紫色渐变。
- 不做大面积黑色界面。
- 不把红豆色当主按钮色。
- 不把豆青色当装饰色，它只表示正向状态。
- 黑芝麻颗粒感以后只能作为局部品牌细节，不进入当前颜色决策。

## 聊天主界面层级

聊天主界面的三栏基础背景从左到右依次变浅：

| 区域         | 色值                                                               |
| ------------ | ------------------------------------------------------------------ |
| Agent 导航栏 | `#F6EFE5`                                                          |
| 会话列表栏   | 约 `#F9F3EA`，由 `background` 以 50% 透明度叠加在 `sidebar` 上形成 |
| 对话区       | `#FBF7EF`                                                          |

`#FFFDF8` 保留给输入框、卡片等浮起表面，不作为三栏基础背景。

三栏明度顺序只约束各区域的基础背景。选中、悬停、按钮等局部交互状态继续使用主题中的对应语义色，并与整体色板保持协调。

三栏之间暂时保留 `1px` 的 `split` 色分隔线，待实际界面视觉验收；如果色块本身已能清楚划分区域，可以移除分隔线。

对话区的基础背景覆盖标题栏、消息流、待处理动作区和输入区外围，使其形成连续的工作面；输入框和卡片等浮起组件仍使用 `#FFFDF8`。

Agent 导航栏中的未选中 Agent 使用 `#FFFDF8` 浮起底色和细边框，悬停时轻微变深；当前 Agent 继续使用黑芝麻实心样式。
